它是什么，不是什么

言字卡的本质是字卡传讯：聊天里的每一句话都来自本地字卡池，TA 什么时候回、回几条，由本地概率引擎决定，不经过任何 AI。帮写字卡只做一件事——把「这句话该怎么写」借给外部模型。它不会接管回复，也不会在后台替你聊天。

关掉总开关后，这一页不会发出任何请求；已经写好的卡仍留在字卡库与聊天记录里，照常可用。

隐私与费用

API Key 与生成记录只存在这台设备上；请求直接发给你填的那个接口，言字卡没有中转服务器。生成产生的费用由你的接口账户结算。

如果这一页是 file:// 打开的，很多接口会拒绝网页直接跨域请求；把站点部署成 https 后再连。
